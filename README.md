# Projeto: Vendas Fictícias

Este projeto gera dados de **vendas fictícias** e realiza análises básicas, incluindo gráficos de produtos mais vendidos, faturamento mensal, por estado e por categoria.

---

## Funcionalidades

- Geração de dados fictícios de vendas com produtos, clientes, cidades e estados
- Cálculo de faturamento por pedido
- Classificação de pedidos por status de entrega (Rápida ou Normal)
- Criação de gráficos:
  - Top 10 produtos mais vendidos
  - Faturamento mensal
  - Faturamento por estado
  - Faturamento por categoria
- Salvamento de CSV final e gráficos em pastas separadas

---

## Tecnologias

- Python 3
- Pandas
- NumPy
- Matplotlib
- Seaborn
- OS e datetime
